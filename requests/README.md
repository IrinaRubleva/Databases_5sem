# Запрос 1. Анализ проблемных дарксторов по заменам и отменам заказов.

За выбранный период определить дарксторы, в которых было выполнено не менее 20 заказов и доля заказов с предложенной заменой либо отменой превышает 10%, для каждого даркстора рассчитать общее количество заказов, количество заказов с хотя бы одной предложенной заменой, количество заказов с принятой заменой, количество отменённых заказов, долю заказов с заменами в процентах, долю отменённых заказов в процентах, среднюю итоговую сумму заказа и среднее время сборки в минутах, в результат включить только дарксторы, удовлетворяющие указанным ограничениям, отсортировать результат по убыванию доли проблемных заказов.

# Запрос 2. Поиск заказов и позиций с нарушенной полнотой операционного процесса.

За последние 30 дней найти заказы, для которых бизнес-процесс остался незавершённым или данные между этапами не согласованы, считать проблемными заказы, у которых есть позиция заказа без созданного резерва после подтверждения заказа, завершённая сборка без фактически зафиксированных партий товара, заказ в статусе доставки без созданной записи доставки либо доставленный заказ без успешной операции окончательного списания оплаты, вывести идентификатор заказа, даркстор, дату создания, текущий статус заказа, количество позиций, количество позиций без резервов, признак отсутствия фактической комплектации, признак отсутствия доставки и признак отсутствия успешного списания оплаты. В итоговый результат включать только заказы, для которых найдено хотя бы одно нарушение.

# Запрос 3. Динамика нагрузки на сборку с использованием скользящего среднего.

Для каждого даркстора по дням за выбранный период рассчитать количество завершённых сборок, среднее время одной сборки в минутах и суммарное количество фактически собранных товарных единиц, дополнительно определить скользящее среднее времени сборки по текущему и шести предыдущим дням, а также скользящую сумму количества завершённых сборок за тот же интервал, вывести дату, идентификатор и адрес даркстора, количество сборок за день, среднее время сборки за день, количество фактически собранных единиц, семидневное скользящее среднее времени сборки и семидневную скользящую сумму сборок. Дни без завершённых сборок в анализ не включать.

# Запрос 4. Анализ изменения цен товаров внутри дарксторов.

Для каждого товара и даркстора построить хронологию изменения цены за выбранный период, для каждой записи определить предыдущую установленную цену, абсолютное изменение стоимости и процент изменения относительно предыдущей цены, дополнительно рассчитать количество дней или часов, в течение которых предыдущая цена оставалась актуальной, вывести идентификатор и наименование товара, категорию, даркстор, дату начала действия новой цены, текущую цену, предыдущую цену, абсолютное изменение, процент изменения и продолжительность предыдущего ценового периода, в итоговый результат включить только случаи фактического изменения цены и отдельно выделить изменения более чем на 15% в любую сторону. Результат отсортировать сначала по товару и даркстору, затем по времени изменения цены.


# Запрос 5. Рейтинг поставщиков по качеству поставленных партий.

За выбранный период оценить поставщиков по качеству поставок, для каждого поставщика рассчитать количество принятых партий, количество различных поставляемых товаров, суммарный первоначальный объём поставок, объём списаний по причинам истечения срока годности или порчи, долю списанного объёма относительно поставленного, количество партий, из которых фактически комплектовались заказы, и среднее число дней от приёмки партии до окончания срока годности, затем для каждого поставщика определить его место в общем рейтинге по минимальной доле списаний, а также распределить поставщиков на четыре группы качества, где первая группа содержит поставщиков с наилучшими показателями. Вывести идентификатор и наименование поставщика, количество партий, количество товаров, объём поставок, объём списаний, процент списаний, количество использованных в заказах партий, средний остаточный срок годности при приёмке, место в рейтинге и номер группы качества, учитывать только поставщиков, у которых за период было принято не менее пяти партий.
